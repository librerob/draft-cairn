01 / Recovery

Your words.
Still within reach.

Review a saved answer, then copy it or restore it to an empty, confidently matched field. Nothing is restored automatically.

Protection must have been enabled before the loss. Only successful saves can be recovered. Query-based pages and uncertain field matches support copying only.

03 / Your control

Keep only
what you need.

Choose how much to keep and whether reading saved answers requires a passphrase. Saving continues while the vault is locked. Keep a separate copy of important work.

Optional passphrase vault

Automatic encryption works without a password. Its key is in this profile. The optional vault protects saved answer contents in a copied profile or backup with your passphrase. It does not protect against a malicious live browser, extension access, or malware on an unlocked device.

Unlock lasts until you lock the vault or Chrome / the extension session ends. Reading, search, restore and library changes require unlocking. A forgotten passphrase means losing the saved answers; there is no reset or recovery service.

Capture privacy

Off by default for new installations. Turning this off removes existing titles and field details from recovery drafts. They become copy-only. The exact website origin is still kept with the encrypted answer; full paths, queries and fragments are not stored as text.

Existing recovery drafts move to encrypted memory storage. They disappear when Chrome fully exits, the extension reloads, or the session is cleared. Closing the last window may leave Chrome running in the background. The answer library stays on disk. This mode has a smaller 2 MiB recovery budget; oldest drafts are removed when switching if necessary.

Draft retention

Oldest recovery revisions are removed if the count or storage budget fills; library answers are never evicted. Temporary original pastes expire within one hour. Cleanup runs hourly while Chrome is running and before data is read. Shortening retention also shortens existing drafts.

Library backup

Choose a passphrase-encrypted backup, or a readable JSON file. Exported files are separate copies: locking or wiping the extension does not delete them. Copying answers also exposes them to the system clipboard and clipboard history.

Import adds validated answers. Exact duplicates are skipped. It does not import drafts or enable websites.

Protected websites

Enable a site from the toolbar popup. Access applies to this exact origin in Draft Cairn; Chrome grants host access across ports. Turning protection off keeps existing drafts. Deleting site data removes its drafts and access; manually saved library answers have no site association.

Never capture

Block a whole site from its toolbar popup. To exclude a field, focus it, click the Draft Cairn status, then choose “Never capture this field” in the editor. Fields with the same identity on that page are excluded together. Excluding deletes their recovery drafts. Labels and page paths are not stored in the exclusion list.

Delete extension data

Remove recovery drafts, library answers, site settings, and granted site access. Exported files and your clipboard are outside the extension.
