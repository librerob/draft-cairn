# Microsoft Edge submission handoff

The Chromium MV3 package is prepared for an Edge pilot, not a verified Edge release. No Edge listing has been submitted.

Before submission, load the unmodified ZIP in a fresh current Edge profile and test native host permission approval/denial/revocation, actual toolbar sizing in both themes, saving/restart/recovery, clipboard behavior, shortcut conflicts, and encrypted library backup. Chrome/Linux CI is not Edge evidence.

Use the current extension ZIP, existing local icon/screenshots, accurate listing copy and public privacy policy. Register/open the publisher account in [Microsoft Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/overview), create the Edge add-on listing, and review its current required fields. The Edge listing ID is separate from Chrome; do not promise automatic transfer of saved Chrome drafts or vault keys. Follow the [official publishing guide](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension).

Publisher account verification and submission remain owner actions. The repository contains no payment integration, tracking or remote code.
